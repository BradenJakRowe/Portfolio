# Braden Rowe — Developer Portfolio

A personal portfolio website showcasing my software development projects, technical skills and background as a Computer Science graduate.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub

### Run locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension in VS Code.
4. Explore the portfolio and its interactive features.

No build tools or package installation are required.
